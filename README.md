# masscon-linkedin-media

MASSCON LinkedIn 게시물에 쓰는 **완성된 이미지·영상·PDF만** 보관하는 공개 저장소입니다.
Buffer API가 공개 주소(URL)로만 파일을 받기 때문에 만들었습니다.

- 모든 파일은 공개입니다. 주소를 아는 사람은 발행 전에도 볼 수 있습니다.
- 원본 사진, 기획 문서, 고객·후보 리스트는 올리지 않습니다.
- 폴더는 월별(`2026-11/` 등), 파일 이름은 게시물 이름(`post08.mp4` 등)입니다.
- 업로드는 `C:\Claude Code\linkedIn\tools\publish_media.py`로 합니다.
